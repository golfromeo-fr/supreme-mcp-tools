### H1. Missing `ip_hash` on nginx upstream silently breaks stateful `/mcp` clients
- **Source:** delegate **H1** (`deploy/nginx-lb.conf:5-8`).
- **Why HIGH:** comment at L3-4 promises "Stateful /mcp clients need sticky
  sessions (ip_hash) — stateless clients float freely", but the
  `upstream mcp_cluster` block has no `ip_hash;` directive. Sessions live
  in-process in `StreamableHTTPSessionManager._server_instances` per node
  (per AGENTS.md), so a `POST /mcp` with `Mcp-Session-Id` from client X
  will round-robin across nodes; node B returns HTTP 404 and the client
  must reconnect to node A. Every stateful `/mcp` call after the first
  fails silently.
- **Fix:** add `ip_hash;` to the upstream block OR change the comment to
  "stateless clients only; stateful `/mcp` not supported".
- **File:** `deploy/nginx-lb.conf`.

### H2. No SSE / streaming proxy settings — breaks SSE + long-poll `/mcp`
- **Source:** delegate **H2** (`deploy/nginx-lb.conf:18-23`).
- **Why HIGH:** the `location /` block has no `proxy_http_version 1.1;`,
  no `proxy_buffering off;`, no `proxy_read_timeout` override. Per
  AGENTS.md the multi-transport app serves SSE (`/sse` + `/messages`) and
  streamable HTTP. Default buffering holds SSE events; default 60s
  `proxy_read_timeout` kills long-poll `/mcp` requests.
- **Fix:** add at minimum:
  ```
  proxy_http_version 1.1;
  proxy_buffering off;
  proxy_read_timeout 3600s;
  proxy_send_timeout 3600s;
  proxy_set_header Connection "";
  ```
- **File:** `deploy/nginx-lb.conf`.
